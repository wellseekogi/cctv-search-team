# MEVA 사람 영상 검색 검증 · 2026-11-20

같은 한국어 질문을 같은 인덱스에 반복하면 검색 순위와 점수는 재현됐다. 질문이 지시하는 실제 장면을 찾는 성능과 직전 후보를 다시 가리키는 능력은 별도로 측정했다. 기준 서비스 커밋은 `d2fdf49`다.

## 실제 웹 검색 115회

웹 UI가 호출하는 `POST /search`에 카메라 필터 없이 `combined`, `top_k=5`로 요청했다. 라이브 dev 인덱스는 G340·G341·G421·G506의 첫 10초에서 만든 벡터 127개와 주석 기반 G421 데모의 14개를 포함했다. 인덱스 버전은 전 회차 `94210f5076`였다. SigLIP2가 프레임을 정렬하고 Qwen3.5-4B가 순위·프레임 번호·재생 시각을 받아 답했다.

- **동일 질문 반복.** 한국어 20문항을 매 회차 다른 순서로 5회씩 보냈다. 100회 모두 응답했다. 20문항 모두 상위 5개 항목의 ID, 순서, 코사인 점수가 다섯 번 일치했다. Qwen 답변까지 글자 단위로 같았던 문항은 10/20이었다. 나머지 10개는 표현이나 숫자 표기가 달랐다.
- **답변 시각.** 100회 중 97회는 첫 후보 재생 시각을 0.05초 이내로 안내했고, 3회는 “바로 확인”처럼 숫자를 생략했다. 명시한 시각이 허용 오차 밖인 경우는 0회였다. 로컬 왕복 지연은 중앙값 2.69초, 95백분위 5.24초였다. 동시 사용자 부하 시험은 하지 않았다.
- **표현 변경.** 같은 카페를 묻는 두 질문의 첫 결과가 달랐다. “카페에서 테이블 옆에 있는 사람을 찾아줘”는 G421의 0초, “탁자 곁에 사람이 있는 카페 장면을 보여 줘”는 같은 영상의 5.033초였다.
- **검색할 장면이 없는 경우.** 스키장·수영장·달 표면이라는 음성 대조 질문 3개를 5회씩 보냈다. 15회 모두 후보 5개와 재생 시각을 반환했다. 후보 반환을 해당 장면의 존재 확인으로 해석할 수 없다.
- **직전 결과 참조.** 서로 다른 첫 질문 5개의 실제 대화 이력에 “방금 추천한 결과 중 두 번째 후보는 몇 초부터 보면 돼?”를 붙여 각각 3회 보냈다. 직전 2위 항목이 새 2위에 유지된 경우는 **0/15**였다. 안내 시각은 **12/15가 틀렸고**, 나머지 3회는 다른 항목의 시각이 우연히 같았다. 예를 들어 직전 후보가 7.2초였을 때 새 답변은 9.8초였다. 현재 UI가 전달하는 이력에는 대화 문장만 있고, 서버는 후속 질문 문장으로 다시 검색한다.

라이브 인덱스에 팀 dev 질의 15개의 영상·정답 시간대를 대조하면 `mq_d02`만 정답 구간을 포함한다. 이 질문은 1위였다. 나머지 14개는 상위 5개에서 적중하지 않았다. 이 구성에서 전체 15개의 적중률은 데이터 범위의 영향이 크다.

## 별도 평가 영상의 장면 검색

라이브 카메라와 다른 두 평가 영상 G299(체육관), G638(광장)의 원본 전체 약 10분을 사용했다. 30fps 원본에서 1초마다 전체 프레임을 한 장씩 뽑고 F의 이미지 질의 제외 구간을 적용해 **592장**을 만들었다. 두 영상의 SHA-256과 디코딩 프레임 수를 manifest와 대조했다. 서비스와 같은 SigLIP2 모델로 임베딩하고 정규화된 벡터의 코사인 점수로 정렬했다. 이는 전체 장면 검색용 비교 실험이다.

팀의 eval 텍스트 질문 **12개 전부**를 원문 영어와 고정 한국어 번역으로 각각 검색했다. 두 언어는 같은 사건을 묻는다. 아래 수치는 상위 K개 중 하나라도 **정답 영상과 원본 시간 구간**에 들어간 질문 수다. 사람 박스까지 맞았는지는 이 표에서 채점하지 않는다.

| 전체 프레임 검색 | 1위 적중 | 상위 3개 적중 | 상위 5개 적중 |
|---|---:|---:|---:|
| 한국어 | 1/12 (8.3%) | 1/12 (8.3%) | 2/12 (16.7%) |
| 영어 | 2/12 (16.7%) | 3/12 (25.0%) | 3/12 (25.0%) |
| 무작위 순위 기대값 | 6.6% | 17.0% | 24.6% |

무작위 기준은 각 질문마다 592장 중 정답 구간 프레임이 차지하는 비율로 비복원 추출의 적중 확률을 계산한 뒤 평균한 값이다. 한 질문이 8.3%p를 차지하는 표본이다. 이 시험에서 언어 간 일반적인 우위나 제품의 보장 정확도를 추정하기는 어렵다.

한국어에서 회색 티셔츠와 검은 모자를 쓴 자전거 이용자는 1위, 체육관 옆 문을 닫는 사람은 5위였다. 붐비는 체육관에서 두 사람이 포옹하는 장면은 83위, 테이블 옆에서 전화하는 사람은 160위였다.

두 원본을 다시 디코딩하고 임베딩부터 채점까지 새 프로세스에서 반복했다. 24개 질문·언어 조합의 순위와 사람 위치 채점 결과를 담은 두 JSON 파일의 SHA-256이 일치했다.

## 실제 B → A → C 인덱스의 사람 위치

같은 두 평가 영상에서 **각각 첫 10초**를 B가 탐지·추적하고 A의 hybrid 정책으로 선별한 평가 인덱스 71개에도 위의 12문항을 모두 질의했다. 웹과 같은 프레임 단위 중복 제거를 적용했다. 정답 시간대가 이 인덱스와 겹치는 질문은 **4개**였다.

- **시간대 기준.** 한국어는 1위 3/12, 상위 5개 4/12였다. 영어는 1위 4/12, 상위 5개 4/12였다.
- **사람 위치까지 요구.** 정답 시간대에 있고 반환된 사람 박스가 같은 원본 프레임의 해당 정답 인물 박스와 IoU 0.5 이상이어야 적중으로 셌다. 전체 장면만 반환하면 위치 점수는 0이다. 한국어·영어 모두 상위 5개 적중은 **3/12**였다. 시간대가 있는 네 문항에 한정하면 각각 **3/4**다. 특히 테이블 옆 통화 질문은 양쪽 모두 시간대는 맞았지만 상위 5개에 맞는 사람 박스가 없었다.
